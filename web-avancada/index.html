    O caminho de uma requisição

    Se você entende este desenho, já responde metade da prova. Clique em uma etapa para pausar e ler.

    Quem faz o quê

    settings.py

    Configura o projeto: INSTALLED_APPS, DATABASES, DEBUG.

    urls.py

    Roteia cada URL para uma view. Sem rota, dá 404.

    views.py

    Processa: decide o que buscar e qual template usar.

    models.py

    Estrutura os dados e conversa com o banco via ORM.

    templates/

    Apresenta o resultado em HTML.

    manage.py

    Executa comandos como runserver e migrate.

    Para lembrar: o Model guarda, a View decide, o Template mostra. A View do Django equivale ao Controller do MVC, e o Template equivale à View do MVC.

    Cola da prova

    Leu a palavra da esquerda no enunciado? A resposta costuma ser a da direita. Pesquise para filtrar.

    Como eliminar alternativas:
    • Cuidado com sempre, nunca e apenas: costumam indicar alternativa errada.
    • Se a alternativa descreve outro arquivo ou outro comando, é pegadinha. Pergunte: de quem é essa função?
    • Navegador executando Python, ou banco escolhendo o template, está sempre errado.
    • A certa quase sempre descreve o papel exato do conceito, com o nome técnico correto.

    Comandos essenciais

    Todos rodam no terminal, dentro da pasta do projeto (com o ambiente virtual ativo).

    Comando O que faz
    pip install django Instala o framework (use um venv)
    django-admin startproject nome Cria o projeto (estrutura base)
    python manage.py startapp nome Cria um app dentro do projeto
    python manage.py runserver Servidor de desenvolvimento
    python manage.py makemigrations Gera os arquivos de migração dos models
    python manage.py migrate Aplica as migrações no banco
    python manage.py createsuperuser Cria o administrador do Django Admin
    python manage.py shell Terminal Python com o projeto carregado
    python manage.py collectstatic Reúne arquivos estáticos para o deploy

    Erros comuns (e a causa)

    Models não viram tabelas

    App fora de INSTALLED_APPS ou faltou makemigrations + migrate.

    Template não é encontrado

    App não registrado, ou arquivo fora da pasta templates/.

    Erro 403 ao enviar formulário

    Faltou {% csrf_token %} dentro do form POST.

    Erro 404

    Nenhuma rota do urls.py casou com a URL.

    DoesNotExist ou MultipleObjectsReturned

    get() exige exatamente um resultado. Use filter() ou get_object_or_404.

    Erro 500

    Exceção na view. Com DEBUG=True o Django mostra o detalhe.
