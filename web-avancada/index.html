    Cola da prova

    Leu a palavra da esquerda no enunciado? A resposta costuma ser a da direita. Pesquise para filtrar.

    Como eliminar alternativas:
    • Cuidado com sempre, nunca e apenas: costumam indicar alternativa errada.
    • Alternativa que descreve outro arquivo ou outro comando é pegadinha. Pergunte: de quem é essa função?
    • Se a alternativa diz que o navegador executa Python, ou que o banco escolhe o template, está errada.
    • A certa quase sempre descreve o papel exato do conceito, com o nome técnico correto.

    Comandos essenciais

    Comando O que faz
    pip install django Instala o framework (use um venv)
    django-admin startproject nome Cria o projeto (estrutura base)
    python manage.py startapp nome Cria um app dentro do projeto
    python manage.py runserver Servidor de desenvolvimento
    python manage.py makemigrations Gera os arquivos de migração dos models
    python manage.py migrate Aplica as migrações no banco
    python manage.py createsuperuser Cria o administrador do Django Admin
    python manage.py shell Terminal Python com o projeto carregado
    python manage.py collectstatic Reúne arquivos estáticos para o deploy
