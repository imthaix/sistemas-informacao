Provas e indução

Direta
Da hipótese à tese por álgebra.
Contraposição
Prove ¬Q ⇒ ¬P.
Contradição
Suponha o contrário e ache um absurdo.
Exaustão
Teste todos os casos finitos.
Direta: n = 6q ⇒ 2n = 12q = 4(3q). Como 3q é inteiro, 2n é divisível por 4.
Contraposição: paridades diferentes ⇒ n+m = 2k+2p+1 é ímpar. Logo n+m par ⇒ mesma paridade.

Indução, passo a passo

Provar 1+2+…+n = n(n+1)/2.

  1. Base: n=1: 1 = 1·2/2 ✔
  2. Hipótese: suponha 1+…+k = k(k+1)/2.
  3. Passo: some (k+1): k(k+1)/2 + (k+1)
  4. Álgebra: = (k+1)(k+2)/2
  5. Conclusão: vale para k+1, logo para todo n ≥ 1.
